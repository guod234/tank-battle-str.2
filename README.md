# 坦克大战 - STR

一个使用 HTML5 Canvas 实现的科幻风坦克大战附加题小游戏。无需安装依赖，直接运行即可开始游戏。

## 运行方式

方式一：双击 `run.bat`。

方式二：直接用浏览器打开 `index.html`。

## 操作说明

- `W / A / S / D` 或方向键：移动坦克
- `空格`：发射炮弹
- `1 / 2 / 3 / 4 / 5`：使用已解锁的主角技能
- `P`：暂停 / 继续
- `R`：重新开始
- `Enter` 或点击画面：开始游戏

## 游戏规则

- 消灭全部 10 辆敌方坦克即可获胜。
- 玩家共有 3 条生命。
- 守住画面下方中央的基地；基地拥有 3 点耐久，玩家阵亡或基地被摧毁则失败。
- 砖墙可以被炮弹摧毁，中央 `S T R` 钢墙和地图上随机出现的钢墙不可被摧毁。
- 敌方包含侦察型、突击型、重型、狙击型、冲锋型、护盾型和 Boss，会使用 BFS 路径规划追踪玩家或攻击基地。

## 道具与武器

- 地图会随机刷新更多道具：护盾、急速射击、三向弹幕、机动强化、火力强化、装甲修复、全屏轰炸、无人机、时间减速、EMP 冲击和加分道具。
- 敌方会发射普通炮弹、追踪等离子弹和爆炸火箭弹。
- 玩家击杀连击可以获得额外分数。

## 主角技能

游戏开始拥有 `导弹支援`，之后随时间解锁，最多 5 个技能：

- `1` 导弹支援
- `2` 护盾
- `3` EMP
- `4` 弹幕
- `5` 超频

技能栏位于游戏画面左下角，冷却期间会有暗色遮罩显示进度。

## 友军支援

战斗开始后会陆续出现少量友军坦克，场上最多 2 辆。友军会自动寻找并攻击敌人，被击毁后会在一段时间后重新支援。

## 原创身份标识

游戏中央区域的钢墙由 `S`、`T`、`R` 三个字母组成，同时画面顶部 HUD 也带有 `STR // TANK OPS` 标识。

## 底图说明

游戏内置程序化绘制的「浪尖儿 WavePeak Elite」主题底图：战场中央以低透明度（16%）水印形式呈现波形喇叭图标与文字标识，配合深青色渐变与网格线，不影响游戏视野，也无需外部图片文件。
